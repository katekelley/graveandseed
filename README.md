# Grave and Seed

Website for Grave and Seed LLC, celebration of life planning in Ann Arbor, Michigan.

- Page text lives in `_data/content.yml` and can be edited in Pages CMS (https://app.pagescms.org).
- The page layout is `index.html`, built by GitHub Pages with Jekyll.
- Contact form submissions go through Web3Forms to kate@graveandseed.com's inbox.

## Voice

- Never describe the writing as "plain language," "plain-language" or "plainspoken." The style should speak for itself.
